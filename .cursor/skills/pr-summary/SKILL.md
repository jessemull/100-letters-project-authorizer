# PR Summary

Summarize `origin/main...HEAD` into:

- Title (Conventional Commit style or `[governance]: …`)
- Summary (1–3 bullets)
- Test plan checklist
- Risks / rollback notes

Align with `docs/RELEASES.md` and `docs/CI_CD.md` when deploy-impacting.
